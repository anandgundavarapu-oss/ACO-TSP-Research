# Ant Colony Optimization for Travelling Salesman Problem (ACO-TSP)

## Project Description
This project implements the Ant Colony Optimization (ACO) algorithm to solve the Travelling Salesman Problem (TSP). It uses artificial ants, pheromone updates, and heuristic information to find an optimized travelling route.

## Technologies Used
- Python
- NumPy
- Matplotlib

## Project Files
- `aco_tsp.py` – Main ACO implementation.
- `aco_experiments.py` – Experimental analysis.
- `aco_experiment_results.csv` – Experimental results.
- PNG files – Generated graphs and visualizations.

## How to Run

1. Install the required libraries:

   `pip install numpy matplotlib pandas`

2. Run the main program:

   `python aco_tsp.py`

3. Run the experiments:

   `python aco_experiments.py`

## Project Objective
To implement and evaluate Ant Colony Optimization for finding efficient solutions to the Travelling Salesman Problem.
